# Project Overview

- Project name: LifeLedger
- LifeLedger is a personal accounting application for managing multiple independent accounting units, such as personal funds, living expenses, shared costs, and purpose-specific funds.
- The application supports combined views across accounting units so users can understand overall income, expenses, and balances.
- The domain adapts ideas from double-entry bookkeeping and branch accounting for personal use.
- Internal transactions between accounting units are important because combined views should eliminate them to avoid double-counting.
