# Tech Stack

- Backend: Laravel 13, PHP 8.5
- Frontend: Vue 3 with Composition API
- Page integration: Inertia.js v3
- CSS: Tailwind CSS v4
- Database: PostgreSQL
- Build tool: Vite 8
- Tests: Pest v4 / PHPUnit 12
- PHP formatting: Laravel Pint, laravel preset
- JavaScript and Vue formatting: Prettier
- Prefer the actual versions in `composer.json` and `package.json` when they differ from planning documents.
