# Development Commands

- Start frontend dev server: `npm run dev`
- Build frontend assets: `npm run build`
- Format PHP: `./vendor/bin/pint`
- Check PHP formatting: `./vendor/bin/pint --test`
- Format JavaScript and Vue: `npm run format`
- Check JavaScript and Vue formatting: `npm run format:check`
- Run tests: `php artisan test`
- Run a filtered test: `php artisan test --filter=TestName`
- Run migrations: `php artisan migrate`
- Reset and seed database: `php artisan migrate:fresh --seed`
