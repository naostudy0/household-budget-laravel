# LifeLedger

**LifeLedger** は、複数の会計単位を分けて管理し、  
必要に応じて統合して確認できる **個人向け会計管理アプリ** です。

## このアプリで実現したいこと

通常の家計簿では、収入・支出をひとつの帳簿で管理することが多いですが、  
実際の生活では、用途ごとに管理したい単位が分かれることがあります。

例えば、以下のような会計単位です。

- 個人用の資金
- 生活費
- 共通費
- 目的別の資金

LifeLedgerでは、これらをそれぞれ **独立した会計** として管理しつつ、  
必要に応じて複数の会計を集計し、**全体の収支や残高を確認できること** を目指しています。

## 主な特徴

- 複数の会計単位を分けて管理できる
- 複数会計を合算して、全体の収支・残高を確認できる
- 会計間の資金移動を、集計時に内部取引として相殺できる
- 複数会計を合算した際の二重計上を防げる
- 複式簿記や本支店会計の考え方を参考にしている

## 設計の考え方

LifeLedgerは、単なる収支管理アプリではありません。

**「分けて管理する」** ことと、  
**「まとめて確認する」** ことを両立するために、  
複式簿記や本支店会計の考え方を、個人利用向けに落とし込んで設計しています。
