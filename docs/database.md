# DB設計

## 公開識別子と主キー

ユーザーに見えるURLパラメーターには、推測しにくいUUIDを使う。

一方で、DBの主キーとテーブル間リレーションには、検索・結合の性能を考慮して整数IDを使う。

## accounts

会計単位を管理するテーブル。

| カラム | 用途 |
|---|---|
| `account_id` | 主キー。リレーションで使用する。 |
| `account_uuid` | 公開識別子。URLパラメーターなどで使用する。ユニーク制約を持つ。 |
| `user_id` | 所有ユーザー。`users.user_id` への外部キー。 |
| `name` | 会計単位名。 |

`account_uuid` は公開識別子であり、リレーションには使用しない。
